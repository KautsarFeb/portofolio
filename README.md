# 🌆 Kautsar Febia Nadha Portfolio

Modern Portfolio Website dengan tema GTA VI / Cyberpunk.

## 🚀 Live Demo

https://kautsarfebia.vercel.app

## ✨ Features

- Dark / Light Mode
- Responsive Design
- Framer Motion Animation
- Dynamic Project from Supabase
- Certificate Viewer
- Project Detail Page
- Download CV
- Contact Form

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Supabase
- Vercel
